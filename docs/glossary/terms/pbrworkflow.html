PBR Workflow

Tags: Metalness, Roughness, Base Color, Materials

Physically Based Rendering (PBR) — Definition

Physically Based Rendering (PBR) is a material workflow used in modern game engines such as Unreal Engine and Unity. PBR materials follow real-world lighting principles so assets react consistently under different lighting conditions. The most common workflow uses Base Color, Roughness, Metallic, and Normal maps.


Overview

A successful PBR material starts with accurate real-world values. One of the most common mistakes beginners make is creating base color maps that are too dark. If the albedo is darker than the real material, the surface absorbs too much light and can appear muddy, unrealistic, or difficult to read in-game.

For most non-metal materials, avoid using pure black or extremely dark values in the Base Color map. Real-world materials usually reflect more light than artists expect. Keeping albedo values within realistic ranges helps lighting artists achieve consistent results without having to compensate for incorrectly authored textures.

Important: If a material looks too dark, do not automatically darken the Base Color map. Check your Roughness, lighting setup, exposure, and reference material first.

The Importance of Roughness

If Base Color defines what a material is, Roughness defines how it feels. Roughness controls how light scatters across a surface and is often the most important texture for creating believable materials.

Many beginner materials look flat because the Roughness map lacks variation. Real-world surfaces contain scratches, fingerprints, dirt buildup, worn edges, paint variation, and areas of different surface quality. These subtle changes often contribute more realism than additional color detail.

A strong Roughness map can make two materials with nearly identical Base Color maps appear completely different.

  • Glossy painted metal has lower roughness and sharper reflections.
  • Weathered painted metal has higher roughness with broken-up reflections.
  • Fresh plastic appears smoother than aged plastic.
  • Polished stone reflects light differently than rough concrete.
Pro Tip: When a material feels unrealistic, spend time improving the Roughness map before adding more color variation. Surface response often sells realism better than color alone.

Common PBR Maps

  • Base Color (Albedo): The material's color information with no lighting or shadows baked in.
  • Roughness: Controls how sharp or blurry light reflections appear.
  • Metallic: Defines whether a surface behaves as a metal or non-metal.
  • Normal: Simulates small surface details without increasing polygon count.
  • Ambient Occlusion (AO): Adds subtle contact shadowing in crevices and cavities.

Common Pitfalls

  • Using Base Color values that are too dark.
  • Baking lighting, shadows, or highlights into the Base Color map.
  • Using noisy Roughness maps that lack realistic purpose.
  • Creating materials with nearly uniform Roughness values.
  • Ignoring real-world reference photography.

 

Examples

Compare a brand-new painted metal toolbox to one that has been used for several years. The Base Color may remain similar, but the Roughness map changes dramatically due to scratches, fingerprints, dirt accumulation, and worn edges. These surface variations create the visual storytelling that makes materials feel believable.
